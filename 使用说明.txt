拾分 · 简答练习室（离线版）
================================

安装包：
- Windows：拾分-Windows-安装程序-v1.1.exe（装到当前用户，无需管理员权限）
- Android：拾分-Android-v1.1.apk（Android 7+，安装时需允许未知来源应用）
详细步骤见 dist/安装说明.txt。

一、免安装网页版：怎么打开
1. 先把整个文件夹解压到电脑上（不要在压缩包里直接运行）。
2. 双击「启动拾分.bat」，会用 Chrome 或 Edge 打开一个独立窗口。
3. 如果没有反应，直接双击「index.html」，用浏览器打开即可。
   如果 Windows 弹出安全提示，选择「更多信息 → 仍要运行」。

二、怎么导入自己的题
1. 点左下角「导入题库」。
2. 把 Excel（.xlsx）、Word（.docx）、CSV、TXT、Markdown 或 JSON 拖进去。
3. 表格里至少要有「题目」和「参考答案」两列；其余列可选：
   关键词、解析、标签、难度。
4. 可以点「下载模板」或「下载 Excel 模板」，照着填最省事。
5. 导入前可以预览题数、取消勾选、选择新建题库或追加到已有题库。
6. 如果配置了 AI，还可以点「AI 生成」：上传 Word/Excel/文本或粘贴资料，让 AI 整理成简答题，预览确认后再导入。

注意：旧版 .xls 不支持，请先用 Excel / WPS 另存为 .xlsx。

三、怎么刷
1. 在「今日」点「开始练习」。
2. 先用自己的话写答案，再点「查看参考答案」。
3. 对照关键词和解析，给自己评一个：忘记 / 模糊 / 掌握 / 熟练。
4. 评「忘记 / 模糊」的题会自动进错题本；星标可以收藏。
5. 设置里可以调整每日目标、自动下一题、打乱顺序、深色主题。

四、数据存在哪里
所有题库、进度、笔记只保存在这台电脑的浏览器里，不会上传，也不需要联网。
建议定期打开「设置 → 导出备份」，保存一份 JSON 备份。
清理浏览器数据、换浏览器或换电脑前，请先导出。

五、AI 功能（可选）
拾分本身不带 AI 模型，需要你自己提供一个 OpenAI 兼容的接口：
- 云端：DeepSeek / OpenAI，需要填写 API Key；
- 本地：Ollama / LM Studio，不需要 Key，但需要先启动本地服务。
设置方法：设置 → AI 服务 → 启用 AI → 选服务商 → 填 Base URL / 模型 / Key
→ 测试连接 → 保存。具体可看 docs/ai-guide.md。

配置后可以：
- 练习时点「AI 点评我的答案」：指出命中/遗漏要点，给改进建议；
- 练习时点「AI 提取关键词」：为没有关键词的题补上自检要点；
- 普通导入预览里点「AI 补全关键词」：为缺关键词的题批量补齐；
- 也可以在 AI 设置里打开「导入时自动补全关键词」，普通导入后自动补（最多 20 题）；
- 导入弹窗「AI 生成」：根据资料/主题直接生成简答题。

注意：
- AI 会把当前题目、参考答案和你的答案发送到你配置的服务，可能产生费用；
- API Key 只保存在本机浏览器，不会写入导出备份；
- AI 点评/生成仅供参考，可能有错，请核对参考答案；导入前一定预览；
- 浏览器直连第三方接口可能遇到跨域（CORS），可以改用本地 Ollama 或自建兼容代理；
- AI 导入不支持 PDF/图片/扫描件，请先转成 Word 或文本。

六、遇到问题
- 导入后是 0 题：检查表头是否包含「题目 / 参考答案」，或先用模板填写。
- 双击 bat 没反应：试试直接双击 index.html；或确认电脑安装了 Chrome / Edge。
- 换电脑后题库不见了：用「设置 → 导入备份」恢复之前导出的 JSON。
- 浏览器太旧：需要 Chrome / Edge 103 或更新版本。

详细导入说明见：docs/import-guide.md
