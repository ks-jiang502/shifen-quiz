# 拾分 · 简答练习室

一款**离线优先的简答题刷题软件**。无需安装、无需注册、无需联网，双击就能用。
支持导入 **Excel（.xlsx）、Word（.docx）、CSV、TXT、Markdown、JSON**，把已有的题库整理成可以反复练习的简答题卡。

> 把知识，答成自己的。

---

## 快速开始

### 电脑版 / 安卓版安装包（推荐）

- **Windows 10 / 11**：运行 [`dist/拾分-Windows-安装程序-v1.1.exe`](dist/拾分-Windows-安装程序-v1.1.exe)，按向导安装；默认装到当前用户，无需管理员权限，会创建桌面和开始菜单快捷方式。
- **Android 7.0+**：安装 [`dist/拾分-Android-v1.1.apk`](dist/拾分-Android-v1.1.apk)。这是使用系统 WebView 的离线应用；首次安装需允许“未知来源应用”。学习数据在应用私有目录，卸载会删除，建议先导出备份。
- 两个安装包和说明也打在一起：[`dist/拾分-双端安装包-v1.1.zip`](dist/拾分-双端安装包-v1.1.zip)、[`dist/安装说明.txt`](dist/安装说明.txt)。
- GitHub 发布页：[`v1.1 Release`](https://github.com/ks-jiang502/shifen-quiz/releases/tag/v1.1)。

> Windows 版依赖 Microsoft Edge WebView2 运行时（Windows 11 通常自带；Windows 10 若缺少会提示下载）。安装包未做商业代码签名，SmartScreen 提示时选择「更多信息 → 仍要运行」。

### 免安装网页版

#### Windows

1. 双击 **`启动拾分.bat`**（推荐，会用 Chrome / Edge 的应用窗口打开，更像一个桌面软件）。
2. 或者直接双击 **`index.html`**，用默认浏览器打开。

### macOS / Linux

直接用 Chrome 或 Edge 打开 `index.html`。

**浏览器要求**：Chrome / Edge **103 或更高版本**（导入 xlsx / docx 时依赖浏览器原生的 ZIP 解压能力）。
应用不依赖网络，也不会上传任何文件。

首次打开会自动载入一套 12 题的「认知与学习」示例题库，可以先试一遍再导入自己的资料。

AI 功能是**可选增强**，默认关闭，需要你自己的 API Key 或本地 Ollama。不配置 AI 也能完整使用离线刷题、导入、错题和统计。

## 它能做什么

### 刷简答题

- 先看题，用自己的话作答；答案自动保存，切换题目不会丢。
- 写完再「查看参考答案」，不会一上来就剧透。
- **关键词对照**：根据导入时填写的关键词，在本地标出你的答案命中了哪些要点。
- 自评掌握程度：**忘记 / 模糊 / 掌握 / 熟练**。简答题没有唯一答案，所以由你判断，系统记录掌握度。
- 支持上一题、下一题、跳过、收藏、补充笔记。
- 可开启「自动下一题」，自评后自动推进；也可以关掉，慢慢对照。
- 快捷键：`Ctrl + Enter` 看答案 / 下一题，`Alt + ←/→` 前后切换，`1–4` 快速自评，`F` 收藏。

### 题库

- 导入 xlsx / docx / csv / txt / md / json，支持一次多选文件。
- 导入前先预览：识别出的题数、被跳过的行、警告、每道题的题干与答案摘录。
- 可以取消勾选不想导入的题，也可以选择「新建题库」或「追加到已有题库」。
- 自动跳过同一题库里的重复题目。
- 题库支持搜索、查看全部题目、重命名、删除、导出 CSV、按题练习。
- 支持按知识点（标签）专练。

### 复习与统计

- **错题本**：自评「忘记 / 模糊」的题会自动收进来，可全部重练。
- **收藏夹**：练习时点星标即可收藏，随时回来复习。
- **统计**：每日目标、连续学习天数、掌握度分布、最近 14 天练习节奏、各知识点掌握度、各题库进度。
- 所有题库、进度、收藏、笔记保存在本机浏览器；支持导出 / 恢复 JSON 备份。
- 浅色 / 深色 / 跟随系统主题；适配手机屏幕（390px 宽无横向滚动）。

### AI 学习助手（可选）

支持 **DeepSeek、OpenAI、本地 Ollama、自定义 OpenAI 兼容代理**。在「设置 → AI 服务」里填写 Base URL、模型和 Key，测试连接后启用。

- **AI 点评答案**：对照参考答案，指出命中/遗漏的要点，给出改进建议和示范答案。AI 覆盖率只是参考，不是考试分数。
- **AI 提取关键词**：练习时从参考答案提取 3–8 个可自检的要点；已有题也可补充关键词。
- **AI 补全关键词**：普通导入预览里，为缺少关键词的题批量补齐（每批 8 题）；也可在 AI 设置里开启「导入时自动补全」。 
- **AI 生成题库**：导入弹窗「AI 生成」标签页，上传 Word/Excel/文本或粘贴资料，让 AI 整理成简答题，预览确认后再入库。
- **不上传服务器**：AI 请求直接从你的浏览器发到你配置的接口；API Key 只保存在本机 localStorage，**不会写入导出备份**。
- 未配置、Key 错误、CORS、断网、超时都有中文提示，不会影响普通刷题。

详细配置与各服务商说明见 [AI 使用指南](docs/ai-guide.md)。

## 导入格式

最省事的方式：下载模板，按表头填写，然后拖回应用。

- 应用内：**导入题库 → 下载 CSV 模板**，或题库页右上角「下载模板」。
- 仓库内：[`templates/简答题导入模板.xlsx`](templates/简答题导入模板.xlsx)
- 示例：[`samples/示例题库.xlsx`](samples/示例题库.xlsx)、[`samples/简答题示例.docx`](samples/简答题示例.docx)、[`samples/示例题库.csv`](samples/示例题库.csv)
- 详细说明：[`docs/import-guide.md`](docs/import-guide.md)

### 推荐表头

| 题目 | 参考答案 | 关键词 | 解析 | 标签 | 难度 |
| --- | --- | --- | --- | --- | --- |
| 什么是间隔练习？ | 把复习分散到不同时间点…… | 分散复习、重新提取、长期保持 | 核心是提取，不是重读。 | 记忆、学习方法 | 2 |
| 请简述费曼学习法。 | 选定概念；用简单语言讲给外行…… | 选定概念、简单讲解、发现漏洞 | 讲解能暴露理解断点。 | 学习方法、输出 | 1 |

- 只有「题目」和「参考答案」是必填的；其余列可留空。
- 表头会做模糊匹配，列顺序可以调整；没有表头时按「题目、答案、关键词、解析、标签、难度」的列序读取。
- 标签、关键词用顿号、逗号、分号或换行分隔。
- 难度支持 `1/2/3`、`易/中/难`、`简单/中等/困难`、`easy/medium/hard` 等写法。
- Excel 会读取所有工作表，自动跳过「说明 / 使用说明」类工作表。
- Word 会优先读取表格；没有表格时按段落识别 `1. 题目`、`答案：`、`关键词：`、`解析：`、`标签：` 等标记。

> **不支持旧版 `.xls`**：请先用 Excel / WPS 打开，另存为 `.xlsx` 再导入。
>
> 合并单元格不会自动展开；建议导入前取消合并，确保每行都有完整的题目和答案。

也可以直接「粘贴文本」导入，格式示例：

```text
1. 什么是间隔练习？
答案：把复习分散到不同时间点，让每次复习都需要重新提取。
关键词：分散复习、重新提取、长期保持
解析：核心是提取，不是重读。
标签：记忆、学习方法
难度：2
```

## 数据与隐私

- 所有解析和练习都在浏览器本地完成，**不会上传文件，也不会联网**。
- 数据保存在浏览器的 `localStorage`（键名 `shifen.v1`）。
- 清理浏览器缓存 / 站点数据、更换浏览器或使用隐私模式，可能导致数据丢失。
- 建议定期在 **设置 → 数据 → 导出备份** 保存一份 JSON。换电脑时用「导入备份」恢复。
- 一台电脑上的不同浏览器数据互不相通；用 `启动拾分.bat` 固定用 Chrome / Edge 打开，可以避免找不到数据。

## 开发与测试

纯静态项目，没有构建步骤、没有 npm 依赖。修改 `css/styles.css`、`js/app.js` 后刷新页面即可。

> 如果 `启动拾分.bat` 被 Windows SmartScreen 拦下，选择「更多信息 → 仍要运行」即可；也可以直接打开 `index.html`。

本地起服务（可选）：

```bash
python -m http.server 8765
```

浏览器打开 `http://127.0.0.1:8765/`。

- 导入器自测页：`tests/importer-check.html`
- E2E 脚本：`tests/e2e.mjs`（Chrome CDP，零依赖）
- 最新验收报告：`tests/report.md`

### 已知限制

- `.xls` 旧格式不支持，需另存为 `.xlsx`。
- 简答题无法自动判分；关键词命中只是自检提示，不替代人工判断。
- 导入 xlsx/docx 依赖 `DecompressionStream("deflate-raw")`，旧浏览器（Chrome/Edge < 103）不支持。
- 数据只存在当前浏览器；不做云同步。
- 不支持加密、损坏或仅修改了扩展名的文件。
- AI 功能不是内置模型，需要自己提供 API Key 或运行本地模型；浏览器直连第三方接口可能遇到 CORS，请使用本地 Ollama 或兼容代理。
- AI 生成/点评可能出现错误；请以参考答案和人工判断为准，导入前务必预览核对。
- AI 导入不支持 PDF/图片/扫描件 OCR；请先转成 Word/文本。
