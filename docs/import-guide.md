# 拾分 · 导入指南

拾分支持把已有的简答题整理成文件后一次性导入。所有解析都在浏览器本地完成：文件不会上传到任何服务器，断网也能用。

- 主入口：左侧栏底部「导入」按钮
- 支持拖拽文件、选择文件，以及直接粘贴文本
- 导入前会显示题数与警告，确认后才会写入题库

---

## 1. 支持的格式

| 格式 | 扩展名 | 说明 |
| --- | --- | --- |
| Excel 工作簿 | `.xlsx` | 推荐。可包含多个工作表，自动合并所有有效题目 |
| Word 文档 | `.docx` | 优先读取表格；没有表格时读取段落 |
| CSV | `.csv` | 支持逗号、制表符、分号分隔；自动识别编码 |
| 纯文本 | `.txt` | 使用文本解析器，适合从笔记里整理 |
| Markdown | `.md` / `.markdown` | 去掉标题、加粗等标记后按文本解析 |
| JSON | `.json` | 题目数组，或 `{ "questions": [...] }` |
| 旧版 Excel | `.xls` | **不支持**，请先在 Excel / WPS 中另存为 `.xlsx` |

> 浏览器要求：Chrome / Edge 103 或更新版本（ZIP 解压依赖浏览器原生 `DecompressionStream("deflate-raw")`）。不支持加密、损坏或改了扩展名的文件。

---

## 2. 字段说明

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 题目 | 必填 | 一道题一行（表格中）或一道题一个区块（文本中） |
| 参考答案 | 必填 | 支持多行；答案为空的行会被跳过并给出提示 |
| 关键词 | 可选 | 用于“关键词命中”提示，多个用顿号、逗号、分号或竖线分隔 |
| 解析 | 可选 | 展示在参考答案下方 |
| 标签 | 可选 | 用于分类筛选，多个用顿号、逗号、分号或竖线分隔 |
| 难度 | 可选 | `1` 易 / `2` 中 / `3` 难；留空按 `1` 处理 |

难度还接受这些写法（忽略大小写、全半角与空格）：

- 数字：`1`、`2`、`3`
- 中文：`易`、`中`、`难`
- 完整写法：`简单`、`中等`、`困难`、`容易`、`一般`、`较难`
- 英文：`easy`、`medium`、`hard`、`beginner`、`intermediate`、`advanced`
- 星级：`★`、`★★`、`★★★`

---

## 3. 表头与列顺序

表头会做模糊匹配：忽略空格、全角 / 半角、大小写和常见标点。可用的同义词包括：

- 题目：题目、题干、问题、简答题、问答、question、q、content、标题
- 答案：参考答案、标准答案、正确答案、答案、答、answer、a
- 关键词：关键词、关键字、要点、keywords、keyword
- 解析：解析、答案解析、说明、解释、analysis、explanation
- 标签：标签、分类、知识点、科目、tags、tag
- 难度：难度、难易度、difficulty、level

如果第一行附近（前 20 行内）同时识别到「题目」和「答案」表头，就按表头映射列，列顺序可以任意；如果完全没有表头，则按下面的列序读取：

```
题目 | 答案 | 关键词 | 解析 | 标签 | 难度
```

前两列必须分别是题目和答案。只有一列的工作表 / 文件会被跳过。

---

## 4. Excel（.xlsx）

- 读取工作簿中的**全部工作表**，合并所有有效题目。
- 每个工作表独立识别表头；没有表头时按上面的列序读取。
- 自动跳过「使用说明」「填写说明」「说明」「readme」等说明类工作表。
- 支持共享字符串（含富文本多个片段拼接）、内联字符串、数字、布尔值和空单元格。
- 单元格内的换行会保留；公式单元格请先复制为“值”，否则可能读到空内容。
- 合并单元格不会自动展开。建议导入前取消合并，确保每行都有完整的题目和答案。
- 隐藏的工作表也会被读取；如果不想导入，请删除或改成说明类表名。
- 每道题的来源会记录为：`文件名 / 工作表名 / 第 N 行`。

---

## 5. Word（.docx）

### 5.1 表格格式（优先）

文档中如果存在表格，导入器会优先读取表格：

- 第一行能识别到「题目」「答案」等表头时，按表头映射列（列顺序不限）。
- 没有表头时，按 `题目 | 答案 | 关键词 | 解析 | 标签 | 难度` 的列序读取。
- 单元格里的多个段落会用换行连接，适合把多行答案放进一个单元格。
- 只要表格解析出了题目，正文段落就不再参与解析。

### 5.2 段落格式

文档中没有可用表格时，按段落解析。推荐的写法：

```text
1. 什么是间隔重复？它为什么有助于长期记忆？
答案：间隔重复是指按照逐渐拉长的间隔复习同一材料。
它利用遗忘曲线，在记忆即将衰退时安排复习。
关键词：间隔重复、遗忘曲线、复习计划
解析：间隔重复的核心是复习时机，而不是复习总量。
标签：学习方法、记忆
难度：1
```

- 题号支持：`1.`、`1、`、`第1题`、`Q1`、`问：`。
- 标签支持：`答案：`、`参考答案：`、`标准答案：`、`答：`、`关键词：`、`关键字：`、`解析：`、`答案解析：`、`标签：`、`分类：`、`难度：`。
- 答案可以写多行：标签之后的普通行会继续归入当前字段，直到遇到下一个标签或下一道题。
- 空行分隔兜底：完全没有题号和标签时，空行分隔的每个区块视为一道题，第一行是题目，其余行是答案。
- 文档开头的说明文字不会被当成题目（在遇到第一道题之前会被忽略）。
- 图片、批注、脚注、域代码和公式不会导入，只读取正文文字。
- 每道题的来源会记录为：`文件名 / 段落 / 第 N 段` 或 `文件名 / 表格1 / 第 N 行`。

## 6. CSV / 纯文本 / Markdown

### CSV

- 自动识别逗号 `,`、制表符 `\t`、分号 `;` 作为分隔符。
- 支持 BOM、双引号包裹字段、字段内逗号 / 换行，以及 `""` 转义的双引号。
- 编码优先按 UTF-8 严格解码，失败后回退 `gb18030`（兼容 GBK / GB2312 保存的中文文件）。
- 有表头时按表头映射，无表头时按列序读取。
- 行号按 CSV 记录计算：字段内换行不会额外增加行号。

示例：

```csv
题目,参考答案,关键词,解析,标签,难度
"什么是间隔重复？","按逐渐拉长的间隔复习……","间隔重复、遗忘曲线","利用遗忘曲线安排复习","学习方法",1
```

### 纯文本 / Markdown

- 与 Word 段落格式使用同一套解析规则（题号、标签、空行兜底）。
- Markdown 会先去掉 `#` 标题、`>` 引用、列表符号、`**加粗**`、`` `代码` `` 等标记。
- 如果 60% 以上的行都包含制表符，会按制表符表格解析。

---

## 7. JSON

支持两种结构：

```json
[
  {
    "question": "什么是闭包？",
    "answer": "函数与其词法环境的组合。",
    "keywords": ["闭包", "作用域"],
    "explanation": "……",
    "tags": ["JavaScript"],
    "difficulty": 3
  }
]
```

```json
{
  "questions": [
    {
      "题目": "进程和线程有什么区别？",
      "答案": "进程是资源分配单位……",
      "关键词": "进程、线程",
      "难度": "中"
    }
  ]
}
```

字段名同样支持第 3 节里的中英文别名；`keywords` / `tags` 可以写成数组，也可以写成用顿号、逗号分隔的字符串。

---

## 8. 粘贴导入

在导入弹窗的粘贴框中直接输入内容，并选择对应的格式：

- `text`：使用文本解析器（题号 / 标签 / 空行兜底）
- `csv`：按 CSV 解析
- `json`：按 JSON 解析

粘贴内容为空、JSON 格式错误等情况会给出中文提示，不会影响当前题库。

---

## 9. AI 生成导入（可选）

导入弹窗的第三个标签页「AI 生成」，适合把课堂笔记、教材段落或零散资料变成简答题。

1. 先在「设置 → AI 服务」配置并启用一个 OpenAI 兼容接口（DeepSeek / OpenAI / 本地 Ollama / 自定义代理）。
2. 打开「导入题库 → AI 生成」。
3. 上传 `.docx` / `.xlsx` / `.csv` / `.txt` / `.md` / `.json`，或直接粘贴文本；也可以在「补充要求 / 主题」里只写一个主题让 AI 出题。
4. 选择题数（5/10/15/20）和难度，点「AI 生成题目」。
5. 生成结果会先进入普通导入预览：检查题干、答案、关键词和提示，勾选后导入。

注意：

- 素材超过 20,000 字时只把前 20,000 字发送给 AI；原文件不会被修改。
- AI 生成内容可能有误，尤其是事实、数字、术语；导入前务必核对。
- 不支持 PDF / 图片 / 扫描件 OCR；请先转成 Word 或文本。
- 素材会发送到你配置的 AI 服务，可能产生费用。
- 普通文件解析（上传文件 / 粘贴文本）全程在浏览器本地完成；只有 AI 生成/补关键词会调用外部服务。
- 普通导入预览里如果发现题目缺关键词，可以点「AI 补全关键词」；已有关键词不会被覆盖。

## 11. 常见问题

**问：导入后题数是 0？**

依次检查：是否有「题目」和「答案」两列；答案列是否整列为空；工作表是否被识别成说明类表；文件是否是加密或损坏的 xlsx。

**问：提示「旧版 .xls 请先另存为 .xlsx」？**

拾分不支持 `.xls`。用 Excel / WPS 打开文件，选择「另存为」，格式选 `.xlsx` 后再导入。

**问：某些行被跳过，并提示“缺少答案”或“缺少题目”？**

空题、空答案不会进入题库，避免练习时出现无内容的卡片。补全后重新导入即可。

**问：提示难度无法识别？**

难度只接受第 2 节列出的写法。无法识别时该题会按 `1`（易）处理，并给出提示；不影响导入。

**问：中文变成乱码？**

CSV / TXT 请尽量保存为 UTF-8；如果是 GBK 文件，导入器会自动回退 `gb18030`。Excel 建议直接保存为 `.xlsx`，不要先导出成其他编码的文本。

**问：答案里的换行还在吗？**

在。Excel 单元格内换行、Word 表格单元格内的多个段落、CSV 引号内的换行都会保留；Word 段落格式中，标签后的连续多行也会合并进同一个答案。

**问：答案里本来有“1. 2. 3.”这样的编号，会被当成新题吗？**

文本解析器中，行首的 `1.`、`2.` 会被当作题号。如果答案内部需要编号，建议改成 `（1）`、`（2）` 或 `①`、`②`，避免被误判为新题。

**问：支持图片、扫描件、PDF 吗？**

不支持。导入器只读取文本，不做 OCR，也不解析 PDF。

**问：文件很大，导入很慢？**

解析在浏览器主线程完成。建议单个文件控制在几千行以内；特别大的题库可以按主题拆成多个文件分批导入。

## 12. 已知限制

- 不支持 `.xls`、`.doc`、`.pdf`、图片和扫描件。
- 不支持加密文件、密码保护的工作簿。
- 富文本只保留文字：图片、批注、脚注、页眉页脚、公式、域代码不会被导入。
- 合并单元格不会展开；表头只在前 20 行内查找。
- 说明类工作表（使用说明、填写说明、说明、readme 等）会自动跳过。
- Word 只读取正文 `word/document.xml`；如果题目只在页眉页脚或文本框里，可能读不到。
- 文本解析器中，答案行首的 `1.` / `2.` 可能被误判为新题（见上方建议）。
- CSV 的“第 N 行”按记录序号计，字段内换行会改变物理行号。
- 浏览器要求 Chrome / Edge 103+；更老的浏览器会给出“不支持原生 ZIP 解压”的提示。

## 13. 给开发者

`js/importers.js` 是纯原生 ES2020 模块（无构建、无外部依赖），加载后暴露：

```js
window.ShifenImport = {
  SUPPORTED_EXTENSIONS,
  parseFiles(files, options),   // 多文件，绝不 throw
  parseFile(file, options),     // 单文件，返回 FileResult
  parseText(text, options),     // 粘贴导入
  buildTemplateCSV()            // 带 BOM 的模板字符串
};
```

自测页：`tests/importer-check.html`。用 Chrome headless 运行：

```text
chrome --headless=new --allow-file-access-from-files --virtual-time-budget=25000 \
  --dump-dom file:///D:/deepseek/workspeace/tests/importer-check.html
```

或启动本地静态服务后访问同一页面：

```text
python -m http.server 8765 --directory D:\deepseek\workspeace
```
